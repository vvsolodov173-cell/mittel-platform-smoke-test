# MITTEL Platform — Smoke Test

Автоматизированная быстрая проверка (smoke test) платформы подбора алмазного инструмента MITTEL.

## Что проверяется

Платформа MITTEL — это система подбора алмазного инструмента и отправки заявок. Smoke test проверяет, что два ключевых сценария работают:

1. **Подбор инструмента** — пользователь выбирает параметры (диаметр, тип сверления, посадка, длина), нажимает «Найти» и получает подходящие коронки.
2. **Отправка заявки** — пользователь добавляет товар в подбор, заполняет контакты и отправляет заявку в CRM.

## Зачем это нужно

Smoke test — это быстрая проверка «система жива?». Если после очередного изменения в коде подбор или заявка перестали работать, тест это покажет до того, как ошибку увидит реальный клиент.
